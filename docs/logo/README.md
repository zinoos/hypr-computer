# hypr-computer logo

A laptop whose screen holds a tile and a red pointer: the agent working on its own desktop. It belongs to the same
family as the [agentControl logo](https://github.com/zinoos/agent-control/tree/master/docs/logo) (same colours,
same animation).

| File | Use |
|---|---|
| `mark.svg` / `mark-dark.svg` | symbol on light / dark backgrounds |
| `mark-mono.svg` | one colour (print, stamps, embroidery) |
| `app-icon.svg` | app icon and avatar; PNGs and `favicon.ico` in `png/` |
| `lockup.svg` / `lockup-dark.svg` | symbol and wordmark |
| `lockup-animated.svg` / `lockup-animated-dark.svg` | README header (respects `prefers-reduced-motion`) |

Colours: ink `#1D1B20`, paper `#F4EFEA`, pointer `#FF5233`. Wordmark: Inter SemiBold, converted to outlines.

- Keep clear space of at least the pointer's height around the logo.
- Minimum size: symbol 16 px (use `app-icon` below 32 px), lockup 120 px wide.
- Don't recolour the pointer, stretch the mark or put the light version on light backgrounds.
